## 🌐 Deploying to the Web (Free & Instant)

### GitHub Pages
1. Create a repository on GitHub (e.g. `sathiamoorthi-portfolio`).
2. Push the files in `C:\Users\kumar\.gemini\antigravity\scratch\sathiamoorthi-portfolio` to `main`.
3. Go to **Settings** → **Pages** → Source: **Deploy from a branch** → Branch: `main` / `root`.
4. Your website will be live at `https://<your-username>.github.io/sathiamoorthi-portfolio`.

### Netlify Drop / Vercel
- Drag and drop the `sathiamoorthi-portfolio` folder directly into [Netlify Drop](https://app.netlify.com/drop) for instant global SSL hosting.
